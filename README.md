# EvalReliability-Mini v0.2: Real-Framework Integration

EvalReliability-Mini v0.2 is a local, deterministic research/portfolio MVP that integrates a real Agent workflow runtime: **LangGraph 1.1.6**. It compares a fail-fast baseline with a checkpointed recovery runner on the same fixed cases and faults.

## Single-command verification

From the repository root:

```bash
python3 run.py
```

The command runs the experiment, validates JSON/JSONL artifacts, runs the full `unittest` suite, writes SHA-256 hashes, and exits non-zero if verification fails. Live outputs are recreated under ignored `artifacts/live/`; the tracked reference snapshot is never overwritten.

On this machine, the shell's default Python inside the repository does not contain LangGraph, while the already-existing `~/ENTER/bin/python3` environment does. `run.py` checks the import first and, only when needed, re-executes itself with that verified local interpreter. It does not alter `PYTHONPATH`, copy packages, install dependencies, or access the network. This bootstrap path is machine-specific and is not a portability claim.

## Feasibility gate

- Package/import: `langgraph` / `from langgraph.graph import StateGraph`
- Version used: `1.1.6`
- Upstream source: <https://github.com/langchain-ai/langgraph/tree/main/libs/langgraph>
- Runtime probe: a compiled `StateGraph` executes a deterministic node and changes `{value: 5}` to `{value: 12}`; this is recorded in `feasibility.json`.
- Environment: the framework was already installed locally. No dependency was installed or downloaded for this project.
- Priority candidate check in the verified runtime: `langgraph` imported and executed; `agents`, `autogen`, and `autogen_agentchat` were not importable. These results are recorded without installing substitutes.

The active installation location can be inspected without network access:

```bash
python3 -c "import importlib.metadata as m; print(m.distribution('langgraph').locate_file(''))"
```

## Where LangGraph actually participates

`LangGraphEvalRunner` builds and compiles a real `StateGraph`:

```text
START -> fetch -> transform -> commit -> END
```

LangGraph schedules all three nodes, carries typed workflow state, checkpoints node progress through `InMemorySaver`, and resumes a failed thread with `graph.invoke(None, config)`. The nodes call local deterministic fetch, transform, and durable commit tools. The integration is not an unused import or a framework-like local shell.

For interruption cases, `commit` writes the side effect and then fails before LangGraph checkpoints node completion. Recovery resumes the same graph thread, re-enters `commit`, and the local idempotency key reuses the existing side effect instead of writing it twice.

## Fixed case and fault design

Both modes use the same 12 deterministic synthetic replay cases and identical fault plan:

| Cases | Fault | Injection point | Count |
|---|---|---|---:|
| `case-001` to `case-003` | none | no injection | 3 |
| `case-004` to `case-006` | timeout | before `transform`, attempt 1 | 3 |
| `case-007` to `case-009` | tool error | before `fetch`, attempt 1 | 3 |
| `case-010` to `case-012` | interruption-resume | after durable `commit` side effect, attempt 1 | 3 |

- **baseline:** one graph invocation; any injected fault becomes a failed terminal result.
- **recovery:** one resume attempt using the same LangGraph thread and its process-local checkpoint.

## Reference result

- Baseline: `3/12` successful; fault recovery `0/9`.
- Recovery: `12/12` successful; fault recovery `9/9`.
- Completed-case replay: terminal counts remain `12 -> 12` in both modes; side-effect counts remain unchanged.
- Interruption cases: one durable side-effect write and one idempotent reuse per case.

Measured latency is preserved in each raw `summary.json` as local run metadata. It is not a benchmark or SLA.

## Artifacts

`artifacts/reference/` is a tracked reference run. `artifacts/live/` is ignored and regenerated by the single command. Each contains:

- `feasibility.json`: real-framework package and runtime probe evidence.
- `case_manifest.json`: exact cases and fault plan.
- `traces.jsonl`: LangGraph invocation, node, fault, resume, tool side-effect, terminal, and replay-skip events.
- `baseline_ledger.json`, `recovery_ledger.json`: attempts, graph invocations, resumes, terminal records, and idempotent side effects.
- `summary.json`, `report.md`: machine-readable and concise results.
- `test-results.txt`: raw test output.
- `SHA256SUMS`: hashes for every other artifact in the directory.

## Model and service boundary

There is **no LLM** in this MVP. It uses local deterministic tools and synthetic cases so failures and expected outputs are exactly reproducible. It makes no network request, uses no external service, account, key, paid API, personal data, or real user traffic.

## Claim boundary and limitations

This is a **research/portfolio MVP, not production-grade infrastructure**. LangGraph's `InMemorySaver` checkpoint is process-local; it does not survive process termination. The atomic JSON ledger persists local terminal records and side effects, but it is not a transactional database or distributed checkpoint store.

The project does not demonstrate distributed production reliability, real model behavior, real SLA, security isolation, concurrency safety, throughput, availability, or general Agent reliability. The `12/12` and `9/9` results apply only to this fixed deterministic case and fault plan.
